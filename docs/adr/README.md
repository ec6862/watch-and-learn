# Architecture Decision Records

This folder records the significant technical decisions behind
watch-and-learn: the problem, the options considered, what was chosen,
and the trade-offs accepted.

Records use a trimmed [MADR 4](https://adr.github.io/madr/) template. They
are never rewritten after acceptance. A changed decision gets a new record
that supersedes the old one.
